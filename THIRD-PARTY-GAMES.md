# Self-hosted game builds

Retro Bowl uses the existing archived build from this repository. Moto X3M and Tiny Fishing runtime files were imported from these public source snapshots:

- https://github.com/tbg69/MotoX3M at `a46976e2b91a65af1d09537f320e76f5b7b83ac1`
- https://github.com/ubg98/TinyFishing at `0d12e52af4d244e333f2f3177b9e6075f2725232`

Game engines, artwork, music, and developer credits remain the property of their respective creators and are not relicensed as the arcade UI. Original runtime files are retained apart from portal/analytics loader removal and page metadata. AG Arcade wraps them in same-origin pages; no Poki launch links are used. Upstream SDK behavior is retained.
